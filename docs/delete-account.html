앱에서 즉시 삭제

  1. RATIO 앱에서 내 Cafe를 엽니다.
  2. 설정을 누릅니다.
  3. 온라인 계정 삭제를 누르고 확인합니다.
  4. Apple로 가입했다면 Face ID 또는 기기 암호로 한 번 더 확인합니다.

계정, Cafe, 레시피, 사진·영상, 개인 기록과 로그인 연결이 삭제됩니다. Apple 연결 토큰 해제와 Storage 파일 삭제까지 성공한 뒤에만 앱이 로그아웃됩니다.
