# Bean Chillin 개발 기여 기록

Bean Chillin는 AI 보조 도구를 사용했지만 제품 요구사항, 기능 우선순위, 데이터 모델, UI 판단, 보안 정책, 법률 문서 범위, 테스트 시나리오와 출시 결정은 프로젝트 소유자가 반복적으로 선택하고 검토했습니다. Git 이력과 이 문서는 그 인간의 창작·편집 과정을 보존하기 위한 기록입니다.

주요 인간 주도 결정:

- Cafe 기반 UGC 구조와 실시간 단계식 추출 경험
- 컵 용량에 따른 원두·물 비율 자동 환산
- 단계별 사진·타이머 및 가변 단계 등록 흐름
- 공개 전 콘텐츠 검토, 신고·차단, 계정 삭제
- 출시 빌드의 로컬 계정·테스트 데이터·영상 업로드 비활성화
- 승인 전 미디어의 비공개 저장과 승인 후 제한 시간 접근

변경 시에는 한 커밋에 하나의 의도를 담고, 요구사항·검토 결과·실기기 테스트 증거를 저장소 또는 비공개 작업 기록에 남긴다. 개인정보, 인증 비밀, 실제 신고 원문은 이 기록이나 공개 저장소에 포함하지 않는다.
